Spelunky

Github Repo

Overview

This is my open-source Unity fan project inspired by Spelunky (Derek Yu). It’s not a 1:1 remake — the goal is to build it in a way that makes sense to me, and to iterate on mechanics, feel, and features as I go.

A big part of the project is learning: I’d love issues and pull requests, especially if you spot problems or have suggestions for better approaches.

In-game controls

  • Move: WASD / left stick
  • Jump: Space / A
  • Rope: Up arrow / Y
  • Bomb: Right arrow / B
  • Sprint: Left Shift / Right trigger
